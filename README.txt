How to publish on GitHub Pages:
1. Extract the ZIP file.
2. Upload index.html, README.txt and the entire assets folder to the ROOT of your GitHub repository.
3. Commit the changes to the main branch.
4. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages deployment to complete.
